# nava-resort# اقامتگاه نوا (NAVA Resort)

وب‌سایت معرفی یک اقامتگاه ساحلی؛ پروژه‌ی دانشگاهی.
صفحه‌ی راست‌به‌چپ (فارسی) و واکنش‌گرا برای موبایل و دسکتاپ.

## امکانات
- صفحه‌ی اصلی با بخش‌های درباره ما، اتاق‌ها، امکانات، گالری، نظرها و تماس
- پنجره‌ی جزئیات برای هر اتاق (قیمت، ظرفیت، ویژگی‌ها) و دکمه‌ی رزرو مستقیم
- فرم رزرو با اعتبارسنجی (نام، شماره تماس، تاریخ ورود و خروج، نوع اتاق) و محاسبه‌ی هزینه‌ی تقریبی
- گالری با نمایش بزرگ عکس و حرکت با فلش‌های صفحه‌کلید
- منوی ثابت که با اسکرول تغییر می‌کند و بخش فعلی را نشان می‌دهد

## ابزارها
HTML5 · CSS3 · Bootstrap 5 (RTL) · Bootstrap Icons · جاوااسکریپت ساده (بدون کتابخانه‌ی اضافه) · فونت وزیرمتن

## ساختار پروژه
```
nava-resort/
├── index.html
├── favicon.svg
├── css/style.css
├── js/main.js
└── images/          عکس‌ها (WebP)
```

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای بارگذاری بوت‌استرپ و فونت‌ها اینترنت لازم است.

## نکته
فرم رزرو فعلاً فقط نمایشی است و اطلاعات را جایی نمی‌فرستد (جای اتصال به سرور در `js/main.js` با `TODO` مشخص شده).
متن نظرها و اطلاعات تماس نمونه هستند.
